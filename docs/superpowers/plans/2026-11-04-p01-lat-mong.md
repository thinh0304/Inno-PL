# Phase 1 · Lát mỏng xuyên suốt · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (người dùng đã chọn: làm trong session, TDD, ghi sổ,
> một lượt review cuối bằng reviewer độc lập, rồi một lượt sửa). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** một đơn hỗn hợp (dịch vụ + thiết bị) đi từ lập đơn → t11 → t22 ∥ t23 → t31 → "đã phê duyệt" trên sandbox, với P&L đúng spec
và số được server chốt.

**Architecture:** công thức P&L và luật mở task là hàm thuần TypeScript trong `src/domain/`, dùng chung cho module (tính ngay khi gõ) và
Code step (chốt số, điều phối). Task là bản ghi entity có `work`; một workflow điều phối chạy khi Task đổi trạng thái (trigger nhóm theo
đơn để không đua), đọc đơn + task + dòng hàng, gọi Code step, rồi tạo/cập nhật task và ghi số chốt.

**Tech Stack:** `@reflexify/agentflow-app-builder` + `agentflow-sdk` + `agentflow-elements` **sdk-v0.9.0**, TypeScript, React 19
(module), Vitest, esbuild (`scripts/build-code.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-04-pl-v2-design.md` · **Lộ trình:** `docs/superpowers/plans/2026-11-04-pl-v2-roadmap.md`

**Tham khảo nền tảng (đọc khi tới task):** skill `agentflow-app-authoring` 0.9.0 (`~/.claude/plugins/marketplaces/agentflow-sdk/
claude-plugin/skills/agentflow-app-authoring/`): `reference/entities.md`, `work.md`, `access.md`, `workflows.md` ("Who a workflow runs
as", "Code steps", "Triggers" kể cả `group`), `steps.md` ("A For Each step"); skill `agentflow-ui-module`; skill `agentflow-app-release`
(`sandbox-json.md`, `sandbox-testing.md`).
