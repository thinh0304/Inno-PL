# Lộ trình triển khai `inno/pl`

**Spec:** `docs/superpowers/specs/2026-11-02-pl-agentflow-design.md` (gọi tắt **Thiết kế**). Mã FR/BR/NFR là của Đặc tả (`docs/source/spec.md`).

Thiết kế là một bản phát hành, nhưng gồm nhiều hệ con. Mỗi hệ con một kế hoạch riêng, làm tuần tự. Mỗi kế hoạch kết thúc ở trạng thái `pnpm build` + `pnpm test` xanh và để lại các interface mà kế hoạch sau dùng. Kế hoạch N+1 được viết chi tiết khi N xong, dựa trên những gì N đã kiểm chứng trên SDK (nhiều bước của nền tảng chưa có ví dụ — Thiết kế C7).

**Kiểm trên sandbox (03/11/2026, `e2e/plan01.sandbox.test.ts`, `pnpm test:sandbox`):** gói cài được với 9 nhóm và mọi grant; seed về đủ (13 / 5 / 24 / 5 / 1 / 15 / 28 bản ghi); trường `percent` lưu **phân số** (`0.08` = 8%) nên giữ nguyên quy ước và ràng buộc 0–1; `configFromRecords()` đọc bản ghi thật ra đúng `DEFAULT_CONFIG`; người ngoài nhóm nhận `403`; workflow `pl_selftest` chạy Code step bundle trên nền tảng ra LN thuần 46.272.444,44, Đạt. Lưu ý cho 02: tạo bản ghi qua API cần `create_form` — `customer`, `supplier`, `staff` chưa có.
